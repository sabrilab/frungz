# Frungz

Jeu de tir à la troisième personne dans un quartier de Paris (Three.js) : mode Domination, Brigade contre Frungz, casse de vitrines, butin, receleur, voitures, parkour, manette PS4.

- `npm install` puis `npm run build` : construit `dist/` (le site statique).
- `npm run dev` : build puis serveur local sur http://localhost:8124
- Mise en ligne : chaque push sur `main` est déployé par Vercel sur https://frungz.vercel.app

Assets : personnages et armes Quaternius (CC0), sons CC0 (voir `public/assets/sfx/LICENCES.md`), voitures (voir `public/assets/cars/VEHICULES-LICENCES.md`).
